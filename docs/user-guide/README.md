# NAMI User Guide

NAMI is a self-hosted workspace for planning industrial network topology, IPv4 addressing, and interface inventory. This guide follows the **Cartoning line** example from an empty plan through a drawing, address review, and handoff.

| Chapter | What you can do |
| --- | --- |
| [1. Get started](01-get-started.md) | Start a local workspace, set the editor password, and build a first plan. |
| [2. Draw and edit topology](02-topology.md) | Place equipment, group VMs, draw links, and work with multiple components. |
| [3. Plan IPv4 addresses and protocol profiles](03-addressing-and-protocols.md) | Define networks, allocate addresses, resolve conflicts, and document interface protocols. |
| [4. Browse and edit interface inventory](04-interface-inventory.md) | Search, sort, edit inline, and apply reviewed bulk changes. |
| [5. Import, export, and share plans](05-import-export-and-sharing.md) | Round-trip inventory in a spreadsheet, transfer a full plan, and create handoff reports. |
| [6. Run and maintain an installation](06-installation-and-maintenance.md) | Configure a database and editor access, check readiness, and back up or restore data. |
